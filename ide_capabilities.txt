480-### MCP (Model Context Protocol) Integration
481-
482-You can connect to MCP servers for enhanced capabilities:
483-
484-#### Qualtrics MCP Server
485-
486-**Survey management via MCP tools:**
487-
488-- **Setup**: Copy `.vscode/mcp.json.example` to `.vscode/mcp.json`
489-- **Host**: `https://<your-qualtrics-datacenter>/API/mcp/survey-crud`
490-- **Auth**: OAuth 2.0 (VS Code prompts for token)
491-- **Transport**: HTTP with Server-Sent Events (SSE)
492-
493-**Capabilities:**
494-
495-- List all surveys in account
496-- Get survey metadata and definitions
497-- Copy surveys between projects
498-- Export survey definitions (QSF format)
499-- Import surveys from QSF files
500-
501-**Example use cases:**
502-
503-- "Show me all surveys with 'TABS' in the name"
504-- "Get the definition for survey ID SV_abc123"
505-- "Copy survey SV_xyz789 to a new project"
506-
507-**Documentation**: [qualtrics-mcp.md](./qualtrics-mcp.md)

509-#### GitHub MCP Servers
510-
511-Two GitHub MCP servers are available with different access levels:
512-
513-| MCP                         | Tool Prefix                   | Access          | Best For                                                                   |
514-| --------------------------- | ----------------------------- | --------------- | -------------------------------------------------------------------------- |
515-| **Local npx server**        | `mcp__github__`               | Full read/write | Comments, PRs, issues, branches, push files, reviews                       |
516-| **Built-in Copilot plugin** | `mcp__plugin_github_github__` | Read-only       | Fast reads: PR details, file contents, search, Copilot agent delegation    |
517-| **`gh` CLI**                | `Bash(gh ...)`                | Full read/write | Workflow dispatch, PR state changes (draft/ready), fallback for all writes |
518-
519-**Local npx server setup** (Claude Desktop — `claude_desktop_config.json`):
520-
521-```json
522-{
523-  "mcpServers": {
524-    "github": {
525-      "command": "npx",
526-      "args": ["-y", "@modelcontextprotocol/server-github"],
527-      "env": {
528-        "GITHUB_PERSONAL_ACCESS_TOKEN": "<token from gh auth token>"
529-      }
530-    }
531-  }
532-}
533-```
534-
535-**Important**: The built-in Copilot plugin injects its own token that cannot be overridden. It is read-only by design. Use the local npx server or `gh` CLI for all write operations.
536-
537-**Token refresh**: The `gho_` OAuth token from `gh auth token` may expire. If MCP writes start failing with 401, run `gh auth refresh` and update the config.
